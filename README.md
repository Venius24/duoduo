# Дуодуо 🦉

Игровая платформа для изучения **английского** и **китайского** с русского языка.
Аналог Duolingo, полностью готовый к деплою и продаже: свой бэкенд, своя база,
два полноценных курса, умные повторения, боссы, лиги и автотесты.

---

## ✨ Что внутри

### Курсы
| Курс | Язык | Объём |
|---|---|---|
| 🇬🇧 **English Flow** | английский | 6 юнитов · 24 урока · 6 боссов |
| 🇨🇳 **Путь дракона** | китайский | 6 юнитов · 24 урока · драконий босс 🐉 |

Каждый урок собирается из **10 типов упражнений**: выбор перевода, сборка фразы
из плиток, ввод текста (для китайского — пиньинем!), аудирование на слух,
аудио-диктант, соединение пар, произношение в микрофон, заполнение пропуска,
тренажёр тонов тона и грамматические карточки.

### Уникальные фичи
- 🧠 **Умные повторения (SRS)** — алгоритм SM-2 сам решает, когда показать слово
- ⏱️ **Боссы юнитов** — сражение на время, проходной балл, звёзды за точность
- 🎙️ **Речевая практика** — распознавание речи прямо в браузере (Web Speech API)
- 🎚️ **Тренажёр четырёх тонов** — цветовое кодирование тонов китайского
- 🔥 **Стрики** с рекордами, 💎 алмазы, ❤️ сердца с автовосстановлением и рефиллом
- 📋 **Квесты дня** с автоматической выдачей награды
- 🏆 **Еженедельная лига** с «живыми» ботами-соперниками (29 участников)
- 🎖️ **10 достижений**, уровни с титулами, идеальные уроки
- 🤖 **ИИ-объяснение ошибок** (опционально, по своему API-ключу)
- 🌙 Тёмная тема, звуковые эффекты без ассетов (Web Audio), озвучка слов (TTS)
- 📱 PWA-манифест, адаптив под мобильные

### Технологии
Next.js 15 (App Router) · TypeScript · Tailwind CSS · Prisma + SQLite ·
JWT (jose) + bcryptjs · Zustand · Vitest + Testing Library

**Ноль внешних сервисов для базовой работы**: база — файл SQLite, озвучка —
встроенный синтез речи браузера, звуки — Web Audio. Работает даже офлайн
после первой загрузки статики.

## 🚀 Быстрый старт

```bash
npm install          # установит зависимости и сгенерирует prisma client
npm run db:push      # создаст prisma/dev.db
npm run db:seed      # демо-юзер + 26 ботов для лиги
npm run dev          # http://localhost:3000
```

**Демо-аккаунт:** `demo@duoduo.app` / `demo123` (кнопка на странице входа)

### Скрипты
```bash
npm run dev        # дев-сервер
npm run build      # прод-сборка
npm start          # запуск собранного
npm test           # все автотесты (60 шт.)
npm run typecheck  # проверка типов
```

## ⚙️ Переменные окружения

Все ключи живут в `.env` (шаблон — `.env.example`). Для работы достаточно
первых двух:

| Переменная | Обязательна | Описание |
|---|---|---|
| `DATABASE_URL` | ✅ | `file:./dev.db` — SQLite (Prisma) |
| `JWT_SECRET` | ✅ | длинная случайная строка для подписи токенов |
| `OPENAI_API_KEY` | ❌ | включает ИИ-объяснения ошибок; без ключа — локальные подсказки |
| `AI_BASE_URL` | ❌ | любой OpenAI-совместимый API (по умолчанию OpenAI) |
| `AI_MODEL` | ❌ | модель (по умолчанию `gpt-4o-mini`) |

> Продажа/передача проекта = передать код + попросить покупателя вписать свои
> значения двух переменных (`DATABASE_URL`, `JWT_SECRET`). Всё остальное уже работает.

## 🌍 Деплой

### Vercel (рекомендуется)
1. Залить репозиторий на GitHub → Import Project в Vercel.
2. В Vercel создать SQLite через Turso/Files или заменить провайдер БД
   (Prisma: сменить `provider` на `postgres` и URL). Для быстрого старта
   подойдёт и файловая БД на постоянном томе.
3. Прописать `DATABASE_URL` и `JWT_SECRET` в Environment Variables.
4. Deploy. Готово.

### Docker (свой сервер)
```bash
docker compose up -d --build
# приложение на :3000, база в volume duoduo-data
```
При старте контейнер сам применяет схему (`prisma db push`) и сеет ботов.

## 🧪 Автотесты

```bash
npm test
```

Покрытие (**60 тестов, 5 файлов**):
- `normalize.test.ts` — нормализация ответов (ё, пунктуация, пиньинь-диакритика), опечатки, китайский ввод
- `core.test.ts` — SRS-алгоритм, уровни/XP, квесты, достижения, тоны, утилиты
- `content.test.ts` — валидация всей структуры курсов: ответы внутри вариантов, уникальность слов, полнота уроков, корректность боссов
- `services.test.ts` — интеграция с реальной БД: регистрация/логин, полное прохождение урока (XP, звёзды, SRS, стрик), проигранный босс, интервалы повторений, лидерборд, идемпотентность квестов, регенерация сердец
- `components/exercises.test.tsx` — рендер и поведение UI упражнений

Тесты используют отдельную БД `prisma/test.db` и не трогают дев-данные.

```
  lib/             SRS, проверка ответов, уровни, квесты, ачивки, TTS/SFX, стор
  server/          prisma, JWT, сервисы (users, lessons, review, leaderboard…)
  components/      ui-кит, оболочка, раннер уроков, 10 типов упражнений
  app/             страницы (лендинг, auth, learn, lesson, review…) + API
src/tests/         автотесты
Dockerfile, docker-compose.yml
```

## 🔧 Как добавлять контент

Курсы описываются декларативно в `src/content/en.ts` / `zh.ts`: слова-кортежи +
предложения + функция сборки упражнений (`f.choiceNew`, `f.wordbank`,
`f.tone`, …). Добавить юнит = добавить объект в массив `units`. Валидность
структуры гарантируют автотесты `content.test.ts`.
